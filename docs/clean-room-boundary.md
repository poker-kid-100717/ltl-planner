# Clean-room reconstruction boundary

The supplied work archive was used only to identify high-level categories of engineering work that are reasonable to demonstrate publicly: CRM/account workflows, LTL capacity planning, yard gate/dock execution, external TMS reads, and inter-application integration.

The portfolio implementation was then authored from scratch.

## Excluded from the reconstruction

- original source files or copied method bodies
- employer/product names
- customer, carrier, broker, employee or vendor data from the work system
- internal host names, resource names, tenant IDs, app-registration IDs or secrets
- company-specific scoring formulas, approval rules or operational thresholds
- database table/column names copied from the work application
- non-public API routes or undocumented write contracts
- screenshots or proprietary UI assets

## Allowed external reference

Alvys is represented as a third-party system because its Public API documentation is publicly available. Only documented read behavior is implemented here.
