2 · Pallet Planner

Dispatch planning — the truck side

  1. Manually enter the won shipment as an Order with six pallets, its weight and its equipment requirement.
  2. In Plan Builder, pick orders + trucks and build a draft.
  3. Review the explanation: hard constraints first, a reason for every unplaced order.
  4. Commit (atomic; 409 if anything changed) then Dispatch.
Open Pallet Planner

3 · Yard Board

Yard execution — the trailer side

  1. Gate: pre-advise, then check the trailer in.
  2. Assign a spot or dock door on the Yard Board.
  3. Load, run the Inspection checklist; failures place a hold.
  4. Mark Ready → Departed; each step is queued in the LTL Outbox.

Five-minute guided tour

  1. FreightDesk → Leads: convert a qualified lead, open the new account, quote a lane, mark the quote Won.
  2. Pallet Planner → Orders: manually create the six-pallet order, then Plan Builder: build a draft and read why each order lands where it does or is left out. Commit, then dispatch.
  3. Yard Board → Gate: check in a trailer, move it to a door, run its inspection to Ready, and depart it.
  4. Yard Board → LTL Outbox, then Pallet Planner → Yard Feed: the same events, delivered and verified.

The demo modules currently open under their original names: Freight Ops, LTL Planner and Yard Ops. Demo writes are rate-limited and data resets daily at 08:23 UTC.
